# Support

ClientNest is an **MIT-licensed starter kit**, not hosted SaaS. You run it on your Supabase project and your host.

Maintainer: **WHH Treasures** · [whhtreasures@gmail.com](mailto:whhtreasures@gmail.com)

## How to get help

1. Read [Quick Start](docs/quick-start.md) and [Troubleshooting](docs/troubleshooting.md).
2. Open a [GitHub issue](https://github.com/waleed-mirza/clientNest/issues) for an install blocker or a defect. Include Node and pnpm versions, whether you used `pnpm supabase:setup`, the failing command, and the error text.
3. Email [whhtreasures@gmail.com](mailto:whhtreasures@gmail.com) for private questions that do not belong in a public issue.
4. Do not send service-role keys.

There is no owed response time.

## Not included

- Building excluded v1 features (Stripe, chat, AI, SSO, i18n, time tracking)
- Custom design systems beyond the four presets and CSS variables
- Running setup on your accounts
- Hosting, DNS, or Resend domain verification

## Demo

The public Harbor demo is read-only and fictional. Do not put real client data there.

Report vulnerabilities privately. See [SECURITY.md](SECURITY.md).
