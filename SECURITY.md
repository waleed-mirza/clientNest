# Security

Report a cross-workspace data leak, a file-access bug, or an authentication bypass through [GitHub private vulnerability reporting](https://github.com/waleed-mirza/clientNest/security/advisories/new) on this repository, or email **WHH Treasures** at [whhtreasures@gmail.com](mailto:whhtreasures@gmail.com).

Do not open a public issue for an unfixed vulnerability. Do not include service-role keys, `.env` values, or session cookies in the report.

Authorization depends on Row Level Security staying enabled.
